ENGINEERING README

Penjelasan Teknis

03

Pipeline WebGL

Canvas → WebGL2 Context → Viewport → Vertex Template (+ Offset) → GPU Buffer → Vertex Shader → Fragment Shader → Rasterizer → Draw Call

makeProgram() meng-compile & me-link vertexSource dan fragmentSource menjadi satu program yang dipakai sepanjang aplikasi (gl.useProgram() hanya dipanggil sekali di awal). positionBuffer dan colorBuffer juga dibuat sekali di awal; setiap kali drawPrimitive() dipanggil, kedua buffer ini diisi ulang dengan data primitive yang sedang digambar sebelum gl.drawArrays() dieksekusi.

Vertex Color dan Interpolasi

Warna tiap vertex dihitung di colorsFor() lalu dikirim lewat attribute a_color. Vertex shader meneruskannya apa adanya ke varying v_color, dan GPU otomatis meng-interpolasi nilai ini di sepanjang permukaan primitive sebelum fragment shader mewarnai tiap pixel — tidak ada perhitungan warna per-pixel manual. Efek ini paling terlihat pada mode warna "rgb", yang mematok tiga vertex pertama triangle ke merah, hijau, dan biru sehingga gradasinya kontras; warna solid lain (merah/hijau/biru/cyan) tetap diberi sedikit variasi kecerahan antar vertex lewat faktor 0.65 + (i % 3) * 0.18 supaya interpolasinya tidak rata.

Multiple Primitive dan Draw Mode

templateFor(type) menyimpan vertex lokal tiap bentuk: triangle 3 vertex, rectangle 6 vertex (dua triangle, karena GPU tidak punya primitive quad bawaan), line 5 titik zig-zag untuk LINE_STRIP, dan points berupa 18 titik yang disusun melingkar lewat perulangan for untuk POINTS. Fungsi modeToGl() memetakan pilihan dropdown Draw mode ke enum WebGL yang sesuai, jadi mengganti draw mode benar-benar mengubah tahap primitive assembly, bukan cuma tampilannya saja.

Dynamic Buffer (Tanpa Transformation Matrix)

Praktikum 2 ini belum memakai transformation matrix — translasi masih dilakukan di sisi CPU. drawPrimitive() menjumlahkan template lokal dengan item.x/item.y untuk mendapat koordinat akhir, lalu array hasilnya di-upload ulang ke positionBuffer lewat gl.bufferData(..., gl.DYNAMIC_DRAW) setiap frame. Pola ini dipakai baik untuk tiga bouncer yang bergerak otomatis maupun primitive terkontrol yang digeser lewat keyboard.

Keyboard

keydown/keyup hanya mengisi objek keys (disimpan dua kali — versi asli dan lowercase — agar Arrow key dan huruf WASD sama-sama terbaca). Fungsi update() membaca keys ini setiap frame untuk menggeser controlled.x/controlled.y secara kontinu (state-based) selama tombolnya masih ditahan, tanpa bergantung pada event.repeat browser yang temponya tidak konsisten. Tombol P dan R sebaliknya dicek langsung di listener keydown dengan syarat !event.repeat, karena aksinya (pause, reset) cukup terjadi sekali per tekan — event-based.

Mouse ke NDC

ndcX = (mouseX − rect.left) / rect.width  × 2 − 1
ndcY = 1 − (mouseY − rect.top)  / rect.height × 2

Konversi ini dihitung langsung di listener mousemove memakai canvas.getBoundingClientRect(), disimpan di mouseNdc, dan ditulis ke HUD. Saat kanvas diklik, koordinat mouseNdc yang sama dipakai sebagai posisi primitive baru — bentuk, draw mode, dan warnanya disalin dari primitive terkontrol lalu didorong ke array spawned.

TUGAS INTI

Tugas Inti yang Diselesaikan

05
Inti 1

Multiple Primitive

Secara default, scene menampilkan 2 triangle, 1 line, dan 1 rectangle sekaligus — lebih dari tiga primitive dengan posisi & ukuran berbeda, memakai dua draw mode berbeda (TRIANGLES & LINE_STRIP) secara bersamaan.

Inti 2

Colored Primitive

Setiap primitive punya warna per-vertex lewat colorsFor(). Salah satu triangle bouncer memakai mode "rgb" sehingga tiga vertex-nya berwarna merah, hijau, biru berbeda — interpolasi warnanya terlihat jelas di permukaan triangle.

Inti 3

Animasi

Array bouncers berisi tiga objek dengan vx/vy masing-masing. Tiap frame posisinya diperbarui, dan arah dibalik saat bounding box-nya (boundsFor()) menyentuh batas NDC -1..1 — terus dianimasikan lewat requestAnimationFrame.

Inti 4

Interaksi

Kombinasi state-based (Arrow/WASD menggerakkan primitive terkontrol selama tombol ditahan) dan event-based (klik kiri spawn, klik kanan undo, P pause, R reset) — melebihi syarat minimal satu jenis interaksi.

CHALLENGE REPORT

Challenge yang Diselesaikan

06
A

Primitive Selector

Dropdown Primitive selector mengganti controlled.type secara langsung, memicu templateFor() mengambil template vertex yang berbeda tanpa mempengaruhi objek lain.

B

Color Control

Enam tombol warna (merah, hijau, biru, cyan, RGB vertex, random) mengganti selectedColor & controlled.color, langsung mempengaruhi hasil colorsFor() pada frame berikutnya.

C

Spawn Primitive

Klik kiri mengonversi posisi pixel ke NDC, menyalin bentuk & warna primitive terkontrol ke array spawned; klik kanan membatalkan (pop) primitive spawn terakhir.

D

Multiple Moving Objects

Tiga bouncers (2 triangle, 1 line) punya posisi awal, kecepatan, dan warna berbeda, masing-masing memantul independen pada batas NDC.

E

Procedural Grid Pattern

drawGrid() membangun garis grid lewat perulangan for dari -1 sampai 1 (step 0.2), digambar sebagai gl.LINES di lapisan paling belakang, bisa dimatikan lewat checkbox.

F

Simple HUD

Elemen HTML di luar canvas menampilkan FPS (dihitung tiap 500ms), jumlah primitive aktif, draw mode primitive terkontrol, dan koordinat NDC mouse — seluruhnya lewat DOM, bukan render WebGL.
