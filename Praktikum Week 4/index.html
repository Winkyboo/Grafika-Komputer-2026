HASIL PRAKTIKUM

Scene utama merender tiga cube dengan 36 vertex per cube dan warna berbeda untuk setiap face. Cube diproses oleh model, view, serta projection matrix 4×4 sebelum dirasterisasi oleh WebGL.

RenderingWebGL 2.0 + GLSL ES 3.00
Cameraposition, target, up, lookAt()
ProjectionPerspective / orthographic
VisibilityDepth buffer + depth test
AnimationDelta time + requestAnimationFrame()

ENGINEERING README

How This 3D Scene Works

03
Model

Rotasi dan translasi menyusun posisi setiap cube di world space.

View

lookAt() mengubah world space berdasarkan kamera dan target.

Projection

Perspective atau orthographic memetakan view space ke clip space.

Depth

Depth buffer menentukan permukaan cube yang terlihat paling dekat.

VERTEX DATA→MODEL MATRIX→VIEW MATRIX→PROJECTION MATRIX→FRAGMENT COLOR

TUGAS INTI

Capaian Utama Praktikum

04
01 · Near & Far Plane

Tiga preset clipping plane digunakan oleh perspective dan orthographic projection.

02 · Depth Buffer

Color dan depth buffer dibersihkan setiap frame sebelum object dirender kembali.

03 · Depth Test

gl.enable(gl.DEPTH_TEST) dapat ditoggle untuk membandingkan visibility object.

04 · Automatic Rotation

Cube utama dan cube tambahan berputar menggunakan delta time.

05 · State-based Camera

Keyboard mengubah state; posisi kamera, target, serta FOV diperbarui per frame.

06 · Event Toggle

Projection, depth, orbit, split view, preset, dan reset memakai aksi sekali tekan.

07 · HUD Camera

HUD menampilkan camera, target, projection, FOV, clipping, depth, orbit, dan split mode.

08 · Aspect Ratio

Projection dibangun menggunakan perbandingan lebar dan tinggi canvas aktif.
