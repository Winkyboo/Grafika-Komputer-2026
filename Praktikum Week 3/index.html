LAPORAN PRAKTIKUM

Ringkasan & Dokumentasi

02

Interactive Transformation Playground ini mendemonstrasikan implementasi Matriks Transformasi (Translasi, Rotasi, Skala) pada arsitektur WebGL2. Geometri objek dipertahankan secara konstan di Local Space (CPU), sementara pemosisian akhir pada layar dihitung secara matematis menggunakan pengalian matriks Column-Major pada GPU melalui variabel seragam (u_matrix).

Konvensi Matriks (matrix3.js)

TransformasiLogika DasarOperasi
IdentityMatriks dasar yang tidak merubah nilai[1, 0, 0, 0, 1, 0, 0, 0, 1]
TranslationMenambahkan offset (tx, ty)x' = x + tx | y' = y + ty
RotationRotasi pivot 2D (Radian)x' = x cosθ - y sinθ
ScalingPerkalian ukuran (sx, sy)x' = sx * x | y' = sy * y
MultiplyPenggabungan matriksP' = M2 * M1 * P

ENGINEERING README

Penjelasan Teknis

03
01

Uniform Matrix & Homogeneous Coordinates

Berbeda dengan praktikum sebelumnya yang mengubah buffer tiap frame, di sini position buffer tetap statis. Vertex ditarik menjadi sistem 3D (Homogeneous) dengan vec3(a_position, 1.0) di Vertex Shader, lalu dikalikan dengan u_matrix yang dikirim CPU. Ini sangat menghemat performa CPU karena GPU menghitung transformasinya secara paralel.

02

Transform Order (TRS)

// Column-Vector Convention: P' = T * R * S * P
matrix = Mat3.multiply(matrix, T);
matrix = Mat3.multiply(matrix, R);
matrix = Mat3.multiply(matrix, S);

Urutan perkalian matriks ini sangat penting karena perkalian matriks tidak komutatif. TRS (Scale, lalu Rotate, lalu Translate) akan membuat objek membesar secara proporsional, berputar di tempat asal lokalnya, baru kemudian digeser ke posisi dunia.

03

Hierarchical Scene Graph (Parent-Child)

Sistem Parent-Child disimulasikan pada Object A dan Object Child (segitiga pink). Matriks Child tidak dikalikan dengan identitas dunia, melainkan dengan matriks dunia dari induknya: ChildWorld = ParentWorld * ChildLocal. Akibatnya, saat Object A bergeser atau berotasi, Child akan otomatis mengikuti dengan tetap menjaga offset lokalnya.

04

Texture Mapping 2D

Fungsi loadTexture menginisialisasi tekstur tunggal 1x1 piksel sebagai tempat (placeholder) sementara, lalu mengunduh gambar asinkronus (CORS anonymous). Fragment Shader diatur dengan uniform toggle (u_use_texture) dan sampler2D untuk menarik warna piksel secara presisi dari UV texcoords.

05

State-Based Input & Delta Time

Kontrol objek dikelola lewat manipulasi state map keys yang dicatat melalui event keydown dan keyup. Laju pergerakan diatur berkesinambungan dengan variabel dt (Delta Time, selisih waktu antar frame) memastikan kecepatan tetap konsisten pada berbagai kondisi Refresh Rate layar.

06

Dynamic Screen Clamping

Untuk mencegah objek pemain tembus layar saat ukurannya membesar (Scale), fungsi batas ruang dinamis digunakan. Batas 1.0 sampai -1.0 dikurangi padding fisik objek yang sudah dikalikan skala terkini (vertexSize * object.scale), mengunci presisi tepi geometri ke tepi Canvas.

TUGAS INTI

Capaian Utama Praktikum

04
Inti 1

Matrix Uniform & Homogeneous

Mempertahankan geometri objek pada local coordinate GPU, lalu menggeser posisinya menggunakan matriks transformasi 3x3 yang dikirim sebagai uniform ke Vertex Shader.

Inti 2

Reusable Geometry Buffer

Mendemonstrasikan efisiensi memori dengan menggunakan satu data geometri (segitiga) untuk merender beberapa objek (Object A dan B) di posisi world coordinate yang berbeda.

Inti 3

State-Based Input & Delta Time

Mengelola pergerakan interaktif (translasi, rotasi, skala) secara kontinu menggunakan state keyboard (bukan sekadar event-based) dan deltaTime agar kecepatan konsisten.

Inti 4

Transform Order & Animasi

Membuktikan pengaruh komposisi pengalian matriks (T × R × S vs R × T) terhadap pivot rotasi objek, serta mengimplementasikan animasi parametrik otomatis (putaran & detak skala).

CHALLENGE REPORT

Challenge yang Diselesaikan

06
A

Reset Transform

Tombol R bersifat diskrit (Event-based) mereset translasi ke (-0.35, 0), skala ke (1, 1), dan sudut putaran ke 0° memulihkan wujud awal.

B

Transform Presets

Tombol 1, 2, dan 3 menyediakan pintasan konfigurasi langsung menuju tiga set parameter Posisi, Skala, dan Orientasi yang berbeda secara instan.

C

Toggle Order & HUD

Tombol T mengganti aliran hitung dari matriks TRS normal ke matriks Translate → Rotate, mengubah efek pivot rotasi. Teks HUD turut bereaksi mengikuti mode aktif.

D

Mouse Translation

Event mousedown membaca posisi client, menyesuaikan koordinat bounding kanvas, dan merubahnya jadi -1 hingga 1 (NDC) untuk teleportasi posisi objek.

E

Parent & Child

Menghadirkan objek pink kecil yang koordinat matriks lokalnya dikalikan berurutan dengan Model Matriks Object A, sehingga menciptakan pautan fisik anak ke induk.

F

Simple Orbit Composition

Implementasi murni matriks (tanpa simulasi kosinus/sinus mentah) yang mengomposisikan rotasi poros utama dan pergeseran radius, ditambah Texture mapping Frieren.
