ENGINEERING README

How This Playground Works

02

Perbedaan Teknis

Event-based

keydown dan klik menangkap aksi sesaat seperti reset, pause, perubahan warna, serta pembuatan circle. Translasi langsung dari keydown dapat bergantung pada keyboard repeat browser.

State-based

keydown/keyup hanya mengubah state tombol. updatePlayer() membaca state setiap frame sehingga gerak lebih stabil, mendukung diagonal, dan tidak bergantung pada delay repeat.

DATA / STATE→UPDATE LOOP→CANVAS API DRAW
Posisi, ukuran, warna, velocity, state keyboard, dan koordinat mouse diubah sebagai data. Fungsi draw meneruskan data tersebut ke Canvas 2D API pada setiap frame.

CHALLENGE REPORT

Challenge yang Diselesaikan

03

Setiap challenge mengubah data aplikasi, kemudian animation loop menggambar state terbaru ke canvas. Bagian ini menjelaskan perilaku dan konsep grafika yang diterapkan pada setiap challenge.

01

Keyboard Movement

Player Frieren bergerak dengan tombol WASD atau Arrow. Event keydown dan keyup menyimpan status tombol, lalu updatePlayer() menerapkan translasi secara kontinu pada setiap frame.

Konsep: state-based input, translasi, multi-key movement
02

Mouse Coordinate

Posisi mouse ditampilkan secara real-time sebagai pasangan koordinat (x, y). Nilainya dihitung relatif terhadap canvas sehingga pengguna dapat melihat hubungan pointer dengan sistem koordinat 2D.

Konsep: canvas coordinate, scaling, real-time feedback
03

Bouncing Object

Bola ungu bergerak menggunakan speedX dan speedY. Ketika tepi bola menyentuh batas canvas, nilai velocity dikalikan -1 sehingga arah geraknya berbalik.

Konsep: position, velocity, boundary check
04

Follow Mouse

Follower circle mengambil nilai mouse.x dan mouse.y dari event mousemove. Posisi pointer dikonversi ke koordinat canvas agar tetap tepat saat ukuran tampilan berubah.

Konsep: mouse coordinate, pointer state
05

Click to Create Circle

Setiap klik kiri membuat object circle baru dan menyimpannya ke array clickedCircles. Klik kanan menghapus circle terakhir sebagai undo, sedangkan tombol Clear Circles menghapus seluruh isi array.

Konsep: array of objects, mouse event, redraw
06

Trail Mode

Mode ini menghentikan pemanggilan clearCanvas() pada setiap frame. Pixel dari frame sebelumnya tetap terlihat sehingga objek bergerak meninggalkan jejak visual.

Konsep: frame buffer, clear vs. persistent frame
07

Multiple Moving Objects

Dua sprite Frieren memiliki data posisi, ukuran, dan kecepatan masing-masing. Keduanya diperbarui serta memantul secara independen pada setiap frame.

Konsep: object data, independent update loop
