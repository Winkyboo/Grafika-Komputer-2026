ENGINEERING README

How This Playground Works

02

Perbedaan Teknis

Event-based

keydown dan klik menangkap aksi sesaat seperti reset, pause, perubahan warna, serta pembuatan circle. Translasi langsung dari keydown dapat bergantung pada keyboard repeat browser.

State-based

keydown/keyup hanya mengubah state tombol. updatePlayer() membaca state setiap frame sehingga gerak lebih stabil, mendukung diagonal, dan tidak bergantung pada delay repeat.

DATA / STATE→UPDATE LOOP→CANVAS API DRAW
Posisi, ukuran, warna, velocity, state keyboard, dan koordinat mouse diubah sebagai data. Fungsi draw meneruskan data tersebut ke Canvas 2D API pada setiap frame.
