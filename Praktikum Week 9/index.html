MODELING WORKFLOW

Tahap Pengerjaan

01
01 / BLOCKOUT

Menetapkan bentuk dasar

Cube disusun menjadi badan utama dan tutup atas untuk menetapkan proporsi peti sebelum menambahkan detail.

02 / INSET + EXTRUDE

Membentuk panel depan

Inset membuat batas panel pada face depan. Face bagian dalam kemudian di-Extrude ke arah dalam untuk membentuk area recessed.

03 / LOOP CUT + BEVEL

Mengontrol tepi

Loop Cut menambahkan edge untuk mengatur geometri. Bevel memberi chamfer pada tepi agar bentuk tetap tegas tetapi tidak terlalu tajam.

04 / MODIFIERS

Membangun detail modular

Modifier membantu membuat komponen simetris dan berulang, menambah ketebalan panel, serta merapikan shading.

TOPOLOGY CLEANUP

Perapian Mesh & Scene

Pemeriksaan menjaga bentuk tetap terbaca dan file siap dilanjutkan ke UV serta material.

04
Geometri

Periksa vertex bertumpuk dan gunakan Merge by Distance bila diperlukan. Pastikan tidak ada duplicate geometry yang tidak dibutuhkan.

Normal & shading

Periksa arah normal, gunakan Recalculate Outside bila diperlukan, dan cek bevel yang bertumpuk atau mengganggu shading.

Silhouette & proporsi

Pastikan bentuk peti tetap jelas, detail tidak berlebihan, dan posisi setiap komponen tersusun rapi.

Outliner

LESSONS LEARNED

Kendala & Solusi

06
Render engine tidak dikenali

Nama engine pada script awal tidak cocok dengan pilihan Blender 5.2. Pengaturan diubah ke BLENDER_EEVEE.

File tidak dapat disimpan di Program Files

Lokasi penyimpanan dipindahkan ke folder Downloads yang memiliki izin tulis.

Collection duplikat di Outliner

Outliner dirapikan dan komponen dikelompokkan berdasarkan fungsi agar struktur scene jelas.

Loop Cut otomatis gagal

Loop Cut dilakukan manual dengan Ctrl + R di Edit Mode agar penempatan edge dapat dikontrol.
